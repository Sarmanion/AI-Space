# Общий Алгоритм Решения Задач (АРЗ)

**1. Построение модели «текущей ситуации»**

* **Анализ и уточнение задачи (Надсистемный взгляд)**
  * Систематизация известных параметров, метрик, механик, причинно-следственных связей, данных.
  * **Анализ вводных данных:**
    * Оценить достаточность, однозначность, непротиворечивость, проблемность данных.
      * _Особое внимание_ — ключевым терминам: проверить на «плавающие» смыслы.
    * **Определить:**
      * Не является ли формулировка задачи проверкой компетенций.
      * Контекст продукта, бизнес-модели, экосистемы игрока.
      * Корректный уровень вмешательства.
      * Не является ли проблема симптомом.
      * Является ли описанная проблема действительно проблемой или ожидаемым, закономерным следствием описанных условий.
      * Не решается ли проблема более простым способом, чем предложено в условии (например, балансом вместо изменения механики).
  * **Уточнение несоответствующих данных через:**
    * Поиск
    * Запрос
    * **Достройка (Постулирование):**
      * Дать чёткие определения терминам.
      * Явное обозначение допущений и серых зон.
* **Конкретизация задачи**
  * Декомпозиция задачи — разбить большую задачу на подзадачи.
  * Составить Алгоритм решения задачи.
  * Выделение обязательных критериев решения, элементов ответа и цели.
  * Вывести для подтверждения алгоритма пользователем.
* **Анализ и выявление ключевой проблемы**
  * На основе модели найти основное ограничение или противоречие.

**2. Генерация вариантов решения**

* 3–5 альтернативных подходов с плюсами и минусами.
* Вывести для выбора варианта решения пользователем.

**3. Детальная проработка**

* Проработать по слоям, соответствующим задаче (примеры: концепция, механика, ресурсы, прогрессия, ожидаемые эффекты).

**4. Оформление ответа и самооценка**

* Проверить ответ по чек-листу.
* Сопоставить предложение с критериями успеха.
* При необходимости — итерация.
