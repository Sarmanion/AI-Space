## 1. Мобильный UX и управление

### 1.1. Принципы мобильного UX

| Принцип | Реализация | Обоснование |
|---------|------------|-------------|
| **Одна рука** | Все ключевые элементы в нижней 2/3 экрана | Комфортная игра в транспорте, одной рукой |
| **Крупные цели** | Минимальный размер тач-зоны 48×48 dp | Соответствует гайдлайнам iOS HIG / Material Design |
| **Минимум текста** | Визуальные подсказки вместо инструкций | Казуальная ЦА не читает туториалы |
| **Мгновенный фидбек** | Анимация + звук на каждое действие | Подтверждение ввода, снижение когнитивной нагрузки |
| **Безопасная зона** | Отступы от краёв экрана (notch, home bar) | Корректное отображение на всех устройствах |

### 1.2. Управление

| Действие | Жест | Описание |
|----------|------|----------|
| **Выбор буквы** | Тап по букве в «корзине» | Буква перемещается в активную позицию финальной фразы |
| **Перестановка букв** | Drag-and-drop | Перетаскивание буквы между позициями в финальной фразе |
| **Удаление буквы** | Тап по букве в финальной фразе | Возврат буквы в корзину |
| **Переключение слов** | Свайп влево/вправо или тап по вкладке | Навигация между 5 промежуточными словами |
| **Ввод слова** | Тап по буквам scrambled word | Букры автоматически заполняют клетки в правильном порядке (при верном решении) |
| **Подсказка** | Тап по иконке 💡 | Открытие меню подсказок |
| **Проверка** | Автоматическая | При корректном слове — зелёная подсветка + анимация |

### 1.3. Wireframe основного экрана пазла

```
┌─────────────────────────────┐
│  [←] Уровень 12    [💡] [⚙️] │  ← Верхняя панель (навигация, подсказки, настройки)
├─────────────────────────────┤
│                             │
│      🖼️ КАРИКАТУРА          │  ← Визуальная подсказка к финалу (25% экрана)
│   «Why did the baker...?»   │  ← Подпись-загадка (clue)
│                             │
├─────────────────────────────┤
│ [_ _ _ _ _] ← ФИНАЛЬНАЯ ФРАЗА │  ← Поля для финального ответа (drag-and-drop)
├─────────────────────────────┤
│  🧺 КОРЗИНА БУКВ            │  ← Собран circled letters (10–15 букв)
│  [A][R][E][T][D][Y][U][N]  │  ← Тап = выбор, drag = перестановка
├─────────────────────────────┤
│ [Слово1] [Слово2] ... [5]   │  ← Вкладки переключения слов
├─────────────────────────────┤
│  S C R A M B L E D          │  ← Перемешанные буквы текущего слова
│  [S][C][R][A][M][B][L][E]  │  ← Тап = выбор буквы для решения
├─────────────────────────────┤
│  _ _ _ _ _ _                │  ← Клетки для ответа (circled = ○)
│  ○     ○       ○            │  ← Обведённые позиции видны визуально
└─────────────────────────────┘
```

**Распределение экрана (портрет)**:
- Карикатура + clue: 25%
- Финальная фраза + корзина: 20%
- Промежуточные слова (вкладки + scrambled + клетки): 50%
- Верхняя панель: 5%

## 2. Адаптация механик под мобильный формат

### 2.1. Что сохраняется из оригинала

| Элемент | Сохранено | Почему |
|---------|-----------|--------|
| 5 промежуточных слов | ✅ | Ядро геймплея, подтверждено PDF-правилами |
| Circled letters | ✅ | Уникальная механика Jumble, селективный фильтр |
| Финальная фраза-каламбур | ✅ | Эмоциональный пик, USP игры |
| Карикатура + подпись | ✅ | Семантический ключ к финалу |
| Двухуровневая структура | ✅ | Мета-головоломка = глубина |

### 2.2. Что адаптировано для мобильных

| Оригинал (бумага) | Мобильная адаптация | Обоснование |
|-------------------|---------------------|-------------|
| Ручное заполнение клеток карандашом | Тап по буквам scrambled word → автозаполнение | Ускорение ввода, снижение фрустрации |
| Ручной сбор circled letters | Автоматический сбор при решении слова | Убирает рутину, фокус на финале |
| Нет проверки до конца | Мгновенная валидация каждого слова | Ранний фидбек, предотвращение цепных ошибок |
| Статичная карикатура | Анимированная реакция при победе | Эмоциональное усиление «ага-момента» |
| Нет подсказок | Multi-tier hints (буква / слово / финал) | Снижение фрустрации, монетизация |
| Один пазл в день | Daily + архив + бонусные уровни | Увеличение реиграбельности и retention |
| Нет прогрессии | Экспоненциальная кривая сложности | Ощущение роста мастерства |

### 2.3. Применение паттернов из Jumble_Ref_Patterns.md

| Паттерн | Тема | Применение в мобильной адаптации |
|---------|------|----------------------------------|
| 1.1 Мета-головоломка | Двухуровневая структура | 5 слов → корзина → финальная фраза |
| 1.2 Селективный фильтр | Circled letters | Только обведённые буквы идут в финал |
| 2.1 Карикатура как механика | Семантическая интеграция | Без картинки финал неразрешим |
| 3.3 Fail-forward | Hints | Многоуровневые подсказки с экономической стоимостью |
| 5.1 Мгновенная валидация | Цифровые улучшения | Автопроверка каждого слова |
| 5.2 Автосбор marked letters | Цифровые улучшения | Рутина автоматизирована |
| 5.3 Drag-and-drop | Цифровые улучшения | Тактильное управление финальной анаграммой |
| 8.1–8.6 Антипаттерны | Избегание | Одноуровневая анаграмма, бесконечные hints, отсутствие визуала — исключены |

## 3. Обоснование экспоненциальной сложности

### 3.1. Требование тестового
> «Сложность уровней должна нарастать так, как будто 10-й уровень — это 100-й уровень в игре»

### 3.2. Формула экспоненциального роста

Каждый параметр сложности растёт по формуле:

```
P(n) = P_base × (1 + r)^(n-1)
```

Где:
- `P(n)` — значение параметра на уровне n
- `P_base` — базовое значение (уровень 1)
- `r` — коэффициент роста (подбирается индивидуально для каждого параметра)
- `n` — номер уровня

### 3.3. Параметры и коэффициенты роста

| Параметр | P_base (ур. 1) | Коэффициент r | Значение на ур. 10 | Значение на ур. 100 | Почему экспонента |
|----------|----------------|---------------|--------------------|---------------------|-------------------|
| Длина слов | 4 буквы | 0.08 | ~8 букв | ~17 букв | Более длинные слова = больше перестановок, сложнее анаграмма |
| Редкость слов | Common (1) | 0.15 | ~3.5 (Rare) | ~100+ (Obscure) | Редкие слова требуют большего словарного запаса |
| Размер корзины | 8 букв | 0.06 | ~13 букв | ~27 букв | Больше букв = комбинаторный взрыв финальной анаграммы |
| Сложность каламбура | 1 (Homophone) | 0.12 | ~3 (Idiom twist) | ~10+ (Multi-layer) | Сложные каламбуры требуют культурной грамотности |
| Количество «ловушек» | 0 | 0.20 | ~5 | ~100+ | Ложные анаграммы, отвлекающие буквы |
| Время на уровень | 180 сек | -0.03 | ~140 сек | ~90 сек | Обратная экспонента: меньше времени = выше давление |

### 3.4. Почему уровень 10 ощущается как уровень 100

1. **Комбинаторный эффект**: рост нескольких параметров одновременно создаёт мультипликативную сложность, а не аддитивную. Уровень 10 имеет ~8-буквенные слова + редкость 3.5 + корзину 13 букв + каламбур сложности 3. Совокупная сложность ≈ уровню 100 в линейной прогрессии.
2. **Когнитивная нагрузка**: на уровне 10 игрок уже прошёл фазу обучения (уровни 1–5) и входит в фазу мастерства. Ожидания игрока и реальная сложность синхронизированы.
3. **Эмоциональная кривая**: уровень 10 — первый «босс-уровень» в восприятии игрока. Психологически он маркируется как значимый рубеж, что усиливает ощущение сложности.
4. **Математическое обоснование**: при r=0.08 для длины слов, уровень 10 даёт слова длиной ~8 букв. Анаграмма из 8 букв имеет 40 320 перестановок (vs 24 для 4-буквенного слова). Это рост в 1680 раз — эквивалент перехода от уровня 1 к уровню 100 в линейной шкале.
