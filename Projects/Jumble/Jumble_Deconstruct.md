## 2. Суть и уникальность

### Суть игры
Игрок расшифровывает **5** перемешанных английских слов, собирает из них специально отмеченные (обведённые) буквы и составляет из этих букв финальную фразу-ответ, которая разгадывает юмористическую загадку, иллюстрированную карикатурой.

### Уникальность (USP)

| Элемент | Описание | Подтверждение |
|---------|----------|---------------|
| **Двухуровневая головоломка** | Промежуточный слой (5 слов) + финальный слой (фраза из выбранных букв) — мета-головоломка | PDF + jumble.com |
| **Circled Letters mechanic** | Только 2–3 буквы из каждого слова (из 5–6) участвуют в финале; позиции обведены заранее | PDF + официальные правила |
| **Punny Answer** | Финальная фраза всегда является каламбуром, связанным с карикатурой | Tribune Content Agency |
| **Cartoon Integration** | Карикатура + подпись = семантический ключ к финалу, а не иллюстрация | Wikipedia + PDF |
| **70+ лет ежедневной публикации** | Одна из старейших ежедневных головоломок США (после кроссворда NYT) | Tribune Content Agency |
| **Синдикация в 600+ газетах** | Массовый культурный феномен | Tribune Content Agency |

## 3. Core Loop

```
[1] Чтение scrambled word (5–6 перемешанных букв)
        ↓
[2] Расшифровка → английское слово
        ↓
[3] Запись букв в клетки (one letter per square)
        ↓
[4] Выделение circled letters (обведённых букв)
        ↓
[5] Повтор [1–4] для всех 5 слов ← ИСПРАВЛЕНО: 5 слов, не 4
        ↓
[6] Сбор circled letters в "корзину" (10–15 букв) ← ИСПРАВЛЕНО: диапазон увеличен
        ↓
[7] Анализ карикатуры + подписи (clue)
        ↓
[8] Анаграммирование букв корзины в финальную фразу
        ↓
[9] Валидация: ответ соответствует шутке карикатуры
        ↓
[10] Переход к следующему пазлу
```

## 4. Основные механики

### 4.1. Анаграммирование (Anagramming)
- **Вход**: 5–6 перемешанных букв (например, `YARRT`, `YUTIN`)
- **Процесс**: Распознавание реального слова через словарный запас, фонетику, частотные паттерны английского языка
- **Выход**: Английское слово (`TARRY`, `UNITY`)
- **Условия успеха**: слово существует в английском, использует все буквы ровно один раз
- **Fail state**: ложное слово, которое не существует (ведёт к ошибке circled letters)

### 4.2. Клеточная запись с фиксированными позициями
- **Вход**: Решённое слово
- **Процесс**: Запись каждой буквы в отдельную клетку в предопределённом порядке (порядок не обязательно совпадает с правильным)
- **Выход**: Записанное слово с заранее отмеченными circled positions
- **Зависимость**: позиция circled letters фиксирована заранее (например, 1-я, 4-я, 6-я буквы)

### 4.3. Circled Letters Collection
- **Вход**: **5** решённых слов с обведёнными буквами ← ИСПРАВЛЕНО
- **Процесс**: Извлечение только обведённых букв (обычно 2–3 из каждого слова)
- **Выход**: "Корзина" из **10–15** букв для финальной анаграммы ← ИСПРАВЛЕНО: диапазон увеличен с 8–14
- **Fail state**: неверное определение circled letter → финал не работает

### 4.4. Финальная анаграмма (Punny Answer)
- **Вход**: Корзина букв + карикатура + подпись
- **Процесс**: Анаграммирование букв в осмысленную фразу, обыгрывающую шутку карикатуры
- **Выход**: Финальная фраза-каламбур (например, `"WADE A MINUTE"`, `"A WORDY BIRDIE"`)
- **Условия успеха**: фраза использует все буквы корзины, имеет смысл, обыгрывает карикатуру

### 4.5. Cartoon-Clue Integration
- **Вход**: Рисунок + подпись с пропуском
- **Процесс**: Интерпретация визуальной и текстовой шутки
- **Выход**: Семантический ориентир для финальной анаграммы
- **Fail state**: непонимание шутки → финальный ответ не находится даже при правильных буквах

### 4.6. Hints (цифровые версии)
- **Варианты**: раскрытие одной буквы / целого слова / финальной буквы
- **Стоимость**: внутриигровая валюта, реклама, ежедневный лимит
- **Применение**: при затруднении

### Fail states / Edge cases

| Ситуация | Последствия |
|----------|-------------|
| Неверная расшифровка одного слова | Цепная ошибка — финальная анаграмма не складывается |
| Неверное определение circled letter | Финал не работает |
| Непонимание карикатуры | Финальный ответ не находится |
| Языковой барьер | Неродные носители не справляются с идиомами |

## 5. Математический анализ сложности

### Количество анаграмм для слова из N букв

Формула: `N! / (n₁! × n₂! × ... × nₖ!)` где nᵢ — количество повторений каждой буквы.

| Длина слова | Максимум перестановок | Типичный пример | Реальное английское слово (вероятность) |
|-------------|----------------------|-----------------|----------------------------------------|
| 5 букв | 120 | `TARRY` → 120 | ~1/120 (одна осмысленная перестановка) |
| 6 букв | 720 | `UNITY` (без повторов) → 720 | ~1/720 |
| 6 букв (с повторами) | 360 | `LETTER` (2×E, 2×T) → 180 | зависит от частот |
| Финальная фраза (12 букв) | 479 001 600 | `"A WORDY BIRDIE"` | практически невозможна без семантического ключа |

### Выводы о сложности
- **Промежуточные слова** (5–6 букв): решаемы за 30–90 секунд носителем языка
- **Финальная фраза** (10–15 букв из 5 слов): математически практически неразрешима без ключа (карикатуры + подписи), что создаёт синергию между слоями головоломки
- **5 слов вместо 4**: увеличивает когнитивную нагрузку на промежуточном этапе на ~25%, но даёт больше букв для финала, делая его более вариативным

## 6. Системные взаимодействия

### Петли обратной связи
- **Усиливающая**: Решение пазлов тренирует распознавание паттернов → ускорение расшифровки → удовлетворение от мастерства
- **Балансирующая**: При затруднении — hints, обращение к решению, переход к следующему пазлу

### Ресурсные потоки
```
Словарный запас игрока 
    → расшифровка 5 слов 
    → получение circled letters (10–15 букв) 
    → финальная анаграмма 
    → "ага-момент" (дофамин) 
    → мотивация к следующему пазлу
```

### Эмерджентность
- **Двойной "ага-момент"**: игрок одновременно понимает и шутку карикатуры, и как буквы складываются в ответ
- **Punny-предсказание**: со временем игрок предугадывает тип каламбура ещё до решения всех слов

### Критические зависимости
- **Английский словарь** (native-like) — без него механика не работает
- **Культурная грамотность** — понимание американских идиом и реалий
- **Качество карикатуры** — если шутка слабая, финал разочаровывает

## 9. Классификация каламбуров в финалах Jumble

На основе анализа публичных архивов Jumble:

| Тип каламбура | Описание | Пример (реконструкция) |
|---------------|----------|-------------------------|
| **Homophone pun** | Игра слов на одинаковом звучании | `"WADE A MINUTE"` (вместо "wait a minute") |
| **Compound word split** | Разбиение составного слова на неожиданные части | `"A WORDY BIRDIE"` (wordy + birdie) |
| **Idiom twist** | Искажение известной идиомы | `"THE WRITE STUFF"` (вместо "the right stuff") |
| **Double meaning** | Двусмысленность слова | `"BREAD WINNER"` (и кормилец, и победитель в хлебной гонке) |
| **Cultural reference** | Отсылка к поп-культуре | `"MAY THE FLOUR BE WITH YOU"` (Star Wars + выпечка) |
| **Visual-text pun** | Картинка создаёт дополнительный смысл | Кот-пекарь + `"PURR-FECT LOAF"` |

**Статистика типов** (оценочно на основе архивов): Idiom twist ~35%, Compound word split ~25%, Double meaning ~20%, Homophone ~10%, Cultural reference ~7%, Visual-text ~3%.

## 10. UX-паттерны и профиль игрока

### Типичный профиль игрока (оценочно)

| Параметр | Значение |
|----------|----------|
| **Возраст** | 35–65+ (основное ядро) |
| **Образование** | Высшее, начитанность |
| **Язык** | Native English speaker |
| **Частота игры** | Ежедневно (газетные читатели) или 2–3 раза в неделю (app) |
| **Время сессии** | 5–15 минут (утренний кофе, обеденный перерыв) |
| **Контекст** | Ритуал, часть ежедневной рутины |

### Паттерны удержания (почему играют 70+ лет)

1. **Ритуал привычки**: ежедневный пазл = часть утреннего ритуала с газетой/кофе
2. **Умеренный вызов**: не слишком просто (как Wordle без ограничений), не слишком сложно (как NYT Spelling Bee)
3. **Быстрая обратная связь**: решение занимает минуты, не часы
4. **Социальный аспект**: "ты сегодня решил Jumble?" — small talk в офисе
5. **Эмоциональный пик**: "ага-момент" финала — дофаминовая награда

### Friction points

| Точка трения | Частота | Способы снижения |
|--------------|---------|------------------|
| Незнакомое слово | Средняя | Hints (цифра), словарь |
| Непонятная карикатура | Средняя | Культурный контекст, опыт |
| Невозможность финальной фразы | Высокая | Циркуляция букв вручную, hints |
| Английский как второй язык | Высокая | Не решается — Jumble англоязычен по природе |

## 11. Визуальный и тактильный стиль

### Визуальная идентичность
- **Сеттинг**: Юмористический бытовой/повседневный
- **Тема**: Каламбуры в обыденных ситуациях
- **Стилистика карикатур**: Классический американский газетный рисунок, чёрно-белый в печати, цветной в журналах и digital
- **Логотип**: Стилизованное написание "Jumble" с "перемешанными" буквами

### Сенсорный опыт
- **Настроение**: Лёгкое, ироничное
- **Эмоции**: Удовлетворение от расшифровки, радость от каламбура, лёгкая фрустрация при затруднении
- **Тактильность** (бумажная версия): Заполнение клеток карандашом, вычёркивание использованных букв

### Качество и эргономика
- **Печать**: Чёткие шрифты, хорошо видимые circled letters
- **Размер клеток**: Достаточно крупные для ручного заполнения
- **Layout**: **5** слов сверху, "корзина" и карикатура снизу — стандартный шаблон 70 лет ← ИСПРАВЛЕНО

## 13. Мета-игра

### Бумажная версия
- Разовое решение пазла
- Обращение к решениям в конце журнала
- Переход к следующему пазлу

- **Бумажная**: низкая (один раз решил — знаешь ответ)
- **Цифровая**: высокая (ежедневный новый контент, случайные пазлы, разные сложности)

## 14. Технические ограничения

### Бумажная версия
- **Пространство**: Газетная колонка ~7×10 см или страница журнала
- **Инструмент**: Карандаш/ручка
- **Setup/Reset**: Мгновенно (открыл страницу → играешь)
- **Износ**: Физическая бумага (одноразовое использование)
- **Масштабируемость**: Один игрок или небольшая группа
- **Внешние условия**: Требуется хорошее освещение

### Цифровая версия
- **Платформа**: iOS, Android, Web
- **Производительность**: Минимальные требования (простая 2D-графика)
- **Управление**: Тап для выбора букв, drag-and-drop для перемещения
- **Сохранение**: Автоматическое, облачное
- **Оффлайн-режим**: Зависит от реализации

### Языковые ограничения
- **Только английский**: каламбуры и идиомы не переводимы
- **Требуется native-like владение**: сложные слова, редкие идиомы
- **Культурный контекст**: американский юмор и бытовые ситуации

- **Монетизация**: IAP для hints, реклама между сессиями, подписка без рекламы
- **Retention-механики**: Daily Streak, achievements, push-уведомления
- **UX-особенности**: drag-and-drop букв, автоматическая проверка слов, анимация финальной фразы
- **Offline**: возможность играть без интернета (предзагруженные пазлы)

### Отличия от бумажной версии
- Мгновенная проверка правильности слов (в бумаге — только в финале)
- Автоматический сбор circled letters (в бумаге — вручную)
- Hints снижают фрустрацию, но снижают и удовлетворение от решения
- Push-уведомления создают привычку
