## 1. Механика и особенности

### Суть
Мобильная адаптация классической словесной головоломки Jumble: игрок расшифровывает 5 перемешанных слов, собирает обведённые буквы и составляет из них финальную фразу-каламбур, разгадывающую карикатуру. Адаптировано под тач-управление с мгновенной валидацией и экспоненциальной прогрессией сложности.

### Уникальные особенности
1. **Двухуровневая мета-головоломка**: промежуточные слова → селективный сбор букв → финальная семантическая анаграмма
2. **Circled Letters как фильтр**: только 2–3 буквы из каждого слова идут в финал (10–15 букв всего)
3. **Карикатура как механика**: визуал не иллюстрация, а функциональный ключ к решению
4. **Экспоненциальная сложность**: уровень 10 ощущается как уровень 100 за счёт мультипликативного роста параметров
5. **Мгновенная валидация**: каждое слово проверяется при вводе, предотвращая цепные ошибки

### Основные механики
1. **Анаграммирование 5 слов** (5–6 букв каждое)
2. **Клеточная запись с фиксированными circled positions**
3. **Автоматический сбор обведённых букв в корзину**
4. **Финальная анаграмма с семантической валидацией** (карикатура + подпись)
5. **Multi-tier hints** (раскрыть букву / раскрыть слово / раскрыть финальную букву)
6. **Daily Streak + архив** (мета-игра)

### Геймплей
Игрок последовательно решает 5 анаграмм, получая обведённые буквы. После решения всех слов буквы автоматически собираются в корзину. Игрок анализирует карикатуру и подпись, затем составляет финальную фразу-каламбур из букв корзины через drag-and-drop. При правильном ответе — анимация победы и переход к следующему уровню.

### Вид перспективы
2D, портретная ориентация, статичный layout

### Управление
Сенсорное: тапы для выбора букв, drag-and-drop для финальной анаграммы, свайпы для переключения слов

### Целевая аудитория
1. Мидкор казуальные игроки 25–65+
2. Любители словесных головоломок
3. Native English speakers (или адаптированная локализация)

### Интересы / Теги
Word Puzzle, Anagram, Daily Game, Brain Training, Puns, Cartoons

### Похожие по механике
Jumble (оригинал), Wordscapes, Word Cookies, NYT Spelling Bee

## 4. Кор-геймплей

### Кор-луп (цикл игровых действий)

```
1. Выбор текущего слова (вкладка 1–5)
   ↓
2. Анаграммирование: тап по буквам scrambled word → автозаполнение клеток
   ↓
3. Валидация слова:
   3a. Верно → зелёная подсветка + авто-сбор circled letters в корзину
   3b. Неверно → красная подсветка + вибрация (haptic feedback)
   ↓
4. Повтор [1–3] для всех 5 слов
   ↓
5. Анализ карикатуры + подписи
   ↓
6. Финальная анаграмма: drag-and-drop букв из корзины в поля финальной фразы
   ↓
7. Валидация финала:
   7a. Верно → анимация победы + начисление streak + переход
   7b. Неверно → мягкая подсветка ошибки + возможность продолжить
   ↓
8. Переход к следующему уровню
```

### Игровые объекты

| Объект | Описание | Функции | Взаимодействия |
|--------|----------|---------|----------------|
| Scrambled Word | Набор из 5–6 перемешанных букв | Источник букв для решения | Тап → заполнение клеток |
| Клетки ответа | Поля для ввода слова (с marked positions) | Фиксация решения, маркировка circled | Принимают буквы, триггерят валидацию |
| Circled Letters | Отмеченные позиции в клетках | Ключи к финальной фразе | Авто-сбор в корзину при верном слове |
| Корзина букв | Область хранения собранных букв | Рабочее пространство финала | Drag-and-drop в финальные поля |
| Финальные поля | Пустые слоты для финальной фразы | Ввод ответа | Принимают буквы из корзины |
| Карикатура | Юмористический рисунок | Семантический ключ к финалу | Визуальная подсказка |
| Подпись (Clue) | Текст с пропуском | Текстовая подсказка + валидация | Заполняется финальной фразой |
| Hint Button | Кнопка подсказки | Открытие меню помощи | Тратит валюту / показывает рекламу |

### Экономика кора

| Ресурс | Описание | Функции | Источники |
|--------|----------|---------|-----------|
| Coins | Мягкая валюта | Покупка подсказок | Решение уровней, daily reward, реклама |
| Hints | Расходуемый бустер | Раскрытие букв/слов | Покупка за Coins, ежедневный бонус |
| Streak | Серия дней | Бонусные награды | Ежедневное решение |
| Time | Ограничение сессии | Естественный лимит | Реальное время |

## 5. Игровые системы

### Система валидации слов
- Проверка по встроенному словарю при каждом изменении ввода
- Визуальный фидбек: зелёный (верно), красный (неверно), жёлтый (частично верно — опционально)
- Haptic feedback на мобильных устройствах
- Звуковой фидбек: короткий позитивный звук при верном слове

### Система подсказок (Multi-tier Hints)

| Уровень | Действие | Стоимость |
|---------|----------|-----------|
| Tier 1 | Раскрыть одну букву в текущем слове | 50 Coins или реклама |
| Tier 2 | Полностью решить текущее слово | 150 Coins или реклама |
| Tier 3 | Раскрыть одну букву в финальной фразе | 100 Coins или реклама |
| Бесплатно | 1 бесплатная подсказка в день | Daily reward |

### Система прогрессии (Экспоненциальная сложность)

Формула: `P(n) = P_base × (1 + r)^(n-1)`

| Параметр | P_base (ур. 1) | Коэффициент r | Ур. 10 | Ур. 100 |
|----------|----------------|---------------|--------|---------|
| Длина слов | 4 | 0.08 | ~8 | ~17 |
| Редкость слов | 1 (Common) | 0.15 | ~3.5 (Rare) | ~100+ (Obscure) |
| Размер корзины | 8 | 0.06 | ~13 | ~27 |
| Сложность каламбура | 1 | 0.12 | ~3 | ~10+ |
| Ловушки (false anagrams) | 0 | 0.20 | ~5 | ~100+ |
| Время на уровень | 180 сек | -0.03 | ~140 сек | ~90 сек |

**Обоснование**: Уровень 10 ощущается как уровень 100 за счёт комбинаторного эффекта одновременного роста нескольких параметров. Например, 8-буквенные слова имеют 40 320 перестановок (vs 24 для 4-буквенных) — рост в 1680 раз эквивалентен переходу от уровня 1 к уровню 100 в линейной шкале.

Подробные расчёты всех 100 уровней: `Jumble_Balance_Table.md`

### Читы (для тестирования прототипа)

| Чит | Действие | Активация |
|-----|----------|-----------|
| `solve_word` | Решает текущее слово | Кнопка в debug-панели |
| `reveal_letter` | Раскрывает одну букву в финале | Кнопка в debug-панели |
| `skip_level` | Пропускает текущий уровень | Кнопка в debug-панели |
| `show_answer` | Показывает финальный ответ | Кнопка в debug-панели |
| `set_level N` | Переход к уровню N | Input в debug-панели |
| `unlock_all` | Разблокировать все достижения | Кнопка в debug-панели |

Debug-панель доступна всегда в прототипе (кнопка 🔧 в верхнем правом углу).

## 6. Мета-игра

### Игровой цикл мета-игры
```
1. Ежедневный вход → Daily Reward (Coins + бесплатный hint)
   ↓
2. Решение Daily Puzzle → +Streak, +Coins, +XP
   ↓
3. Проверка достижений → разблокировка новых
   ↓
4. Магазин подсказок (опционально)
   ↓
5. Архив → перепрохождение старых уровней
```

### Системы мета-игры

| Система | Описание | Награда |
|---------|----------|---------|
| Daily Streak | Последовательные дни игры | 3 дня: +100 Coins, 7 дней: +300 Coins, 30 дней: эксклюзивный скин |
| Достижения | 20 достижений за мастерство | Coins, титулы, визуальные награды |
| Архив | Доступ ко всем пройденным уровням | Реиграбельность, тренировка |
| Leaderboard | Время решения (опционально) | Социальная конкуренция |

### Экономика мета-игры

| Ресурс | Описание | Функции | Источники |
|--------|----------|---------|-----------|
| Coins | Накопляемая валюта | Покупка hints | Уровни, streak, реклама |
| XP | Опыт игрока | Прогрессия профиля | Решение уровней |
| Stars | Рейтинг уровня | Качество прохождения | Решение без hints, скорость |

### 7.1. Экран основного пазла (Game Screen)

```
┌─────────────────────────────┐
│ [←] Lv.12      [💡] [🔧]   │ ← Верхняя панель (5%)
├─────────────────────────────┤
│                             │
│      🖼️ КАРИКАТУРА          │ ← 25% экрана
│   «Why did the baker...?»   │
│                             │
├─────────────────────────────┤
│ [_ _ _ _ _ _ _ _ _ _ _ _]   │ ← Финальная фраза (drag-drop)
├─────────────────────────────┤
│ 🧺 [A][R][E][T][D][Y][U][N]│ ← Корзина букв (20%)
├─────────────────────────────┤
│ [W1] [W2] [W3] [W4] [W5]   │ ← Вкладки слов
├─────────────────────────────┤
│  S C R A M B L E D          │ ← Перемешанные буквы
│  [S][C][R][A][M][B][L][E]  │ ← Тап для выбора (50%)
├─────────────────────────────┤
│  _ _ _ _ _ _                │ ← Клетки ответа
│  ○     ○       ○            │ ← Circled positions
└─────────────────────────────┘
```

**Распределение экрана (портрет)**:
- Верхняя панель: 5%
- Карикатура + clue: 25%
- Финальная фраза + корзина: 20%
- Промежуточные слова (вкладки + scrambled + клетки): 50%

**Управление на экране**:
- Тап по букве scrambled → перемещение в клетку ответа
- Тап по букве в клетке → возврат в scrambled
- Тап по букве в корзине → перемещение в активный слот финала
- Drag-and-drop → перестановка букв между слотами финала
- Свайп влево/вправо → переключение вкладок слов

## 8. Технические требования для /code

### Структура данных уровня (JSON)

```json
{
  "level_id": 1,
  "words": [
    {
      "scrambled": "YARRT",
      "answer": "TARRY",
      "circled_positions": [0, 3]
    },
    {
      "scrambled": "YUTIN",
      "answer": "UNITY",
      "circled_positions": [1, 4]
    }
  ],
  "final_phrase": {
    "answer": "WADE A MINUTE",
    "clue": "Why did the baker take so long?",
    "cartoon_asset": "cartoon_001.png"
  },
  "difficulty": {
    "word_length_avg": 5,
    "word_rarity": 1,
    "pun_complexity": 1,
    "basket_size": 10
  }
}
```

### Состояние игры (State Machine)

| Состояние | Описание | Переходы |
|-----------|----------|----------|
| MENU | Главное меню | → GAME (start level) |
| GAME | Основной геймплей | → VICTORY, DEFEAT, PAUSE |
| VICTORY | Экран победы | → GAME (next), MENU |
| PAUSE | Пауза | → GAME, MENU |
| SHOP | Магазин подсказок | → MENU |
| ARCHIVE | Архив уровней | → GAME, MENU |

### Требования к прототипу
1. **Single-file HTML**: весь код в одном файле (inline CSS + JS)
2. **Mobile-first**: viewport meta tag, touch events, responsive layout
3. **No external dependencies**: vanilla JS only (без React/Vue/jQuery)
4. **Asset embedding**: картинки как base64 data URI (для автономности)
5. **LocalStorage**: сохранение прогресса (streak, unlocked levels, coins)
6. **Debug panel**: всегда доступна, toggle по тройному тапу
7. **Performance**: 60 FPS на средних мобильных устройствах
8. **Accessibility**: крупные шрифты (min 16px), высокий контраст

### Формат хранения контента
- 10 уровней хранятся как массив JSON внутри HTML-файла
- Картинки — base64-encoded PNG/WebP
- Словарь для валидации — минимальный набор (~200 слов для 10 уровней)
