# Человеческие правила взаимодействия с ИИ

Пользователь для повышения продуктивности работы с ИИ должен:

* **Давать критерии оценки в первой итерации.** Вместе с задачей явно указывать, что должно быть продемонстрировано в ответе (например: «Ответ должен показывать, что ты видишь ловушку ложной дилеммы и группируешь шаги в блоки»). Это резко снижает количество циклов согласования.
* **Явно задавать уровень абстракции.** Вместо общих указаний («будь надсистемнее») давать конкретные инструкции: «Пиши без цифр, без имён исполнителей, без примеров — только логические блоки». Модель интерпретирует конкретные указания лучше, чем абстрактные.
* **Использовать «стоп-сигналы».** Когда ответ уже близок к финалу, давать явную команду «дальше не править, это финал», чтобы пресечь самодеятельность модели по «улучшению».
* **Показывать идеальный пример.** Одна ссылка на образец в нужном стиле заменяет десятки текстовых правок. Модель способна мгновенно адаптироваться к эталону.
* **Указывать на системные ошибки, а не на частные проявления.** Вместо «убери эти цифры» — «перестань давать любые временные оценки без данных». Это быстрее переобучает модель.\
  \
  Эти правила сформулированы ИИ на основе анализа ошибок взаимодействия для повышения эффективности будущих сессий.
